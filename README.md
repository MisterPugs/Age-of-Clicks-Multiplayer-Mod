# ⚡ Age of Clicks - Multiplayer Mod & ModLoader

Модификация для игры **Age of Clicks**, добавляющая полноценный сетевой мультиплеер до 8 игроков, систему моддинга, горячую перезагрузку, тактический чат, ленд-лиз и сетевые сохранения.

---

## 🚀 Основные возможности

- 🌐 **Сетевой Мультиплеер**: Игра по локальной сети (LAN), прямому IP или Steam.
- 💾 **Сетевые сохранения и Горячий Реконнект [F6]**:
  - Хост может сохранить прогресс многопользовательского матча в любой момент на клавишу `F6`.
  - При обрыве соединения или случайном вылете игрок мгновенно восстанавливает управление своей страной без потери прогресса.
- 🚨 **Система ядерного оповещения (DEFCON 1)**:
  - При пуске МБР включается сирена, красная периметральная тревога и верхний тактический банер с таймером обратного отсчёта до падения боеголовки.
- 🤝 **Сетевой Ленд-Лиз и Передача Дивизий [F7]**:
  - Быстрая передача золота союзникам (+10 000, +50 000, +250 000 🪙).
  - Прямая передислокация целых армейских корпусов на баланс союзных государств.
- 💬 **Тактический чат и пинги по карте**:
  - Открытие чата по `Enter` или `T`.
  - `Alt+ЛКМ` — боевой пинг атаки; `Shift+ЛКМ` — защитный маркер обороны.
- 📊 **Сетевая таблица матча [Tab]**:
  - Удержание клавиши `Tab` отображает статус игроков, территории, численность армии, баланс казны и сетевой пинг.
- 👁️ **Режим Наблюдателя (Spectator Mode)**:
  - Возможность судить матчи без управления страной с полным обзором тумана войны.
- 🔄 **Авто-обновление**:
  - Игра автоматически проверяет актуальную версию мода при запуске и сообщает о выходе апдейтов.

## 📥 Установка для игроков

1. Скачайте последний архив **`Age_of_Clicks_Multiplayer_Mod.zip`** из раздела [Releases](https://github.com/MisterPugs/Age-of-Clicks-Multiplayer-Mod/releases/latest).
2. В Steam нажмите правой кнопкой мыши по **Age of Clicks** ➔ **Управление** ➔ **Просмотреть локальные файлы**.
3. Распакуйте папки `app` и `mods` из архива в корневую папку игры (с подтверждением замены файлов).
4. Запустите игру через Steam — в главном меню появится кнопка **«СЕТЕВАЯ ИГРА»**!
